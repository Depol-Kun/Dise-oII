COMO ESTUDIAR TU PROYECTO (0416) COMO CURSO
==================================================
Para cada modulo (eventos, usuario, inscriptos):

PASO 1: Lista
- abre index.php
- identifica botones Nuevo, Editar, Borrar

PASO 2: Alta
- index.php -> nuevo.php -> _form.php -> guardar.php -> modelo insert()

PASO 3: Edicion
- index.php -> editar.php -> _form.php -> actualizar.php -> modelo update()

PASO 4: Baja
- index.php -> borrar.php -> modelo delete()

PASO 5: Validacion
- revisa reglas de POST/GET en guardar.php y actualizar.php

PASO 6: SQL
- abre metodos getAll/getByID/insert/update/delete en lib/

PASO 7: Redirecciones
- revisa en cada accion: a donde va si ok y si error

Checklist por modulo:
[ ] Alta funciona
[ ] Edicion funciona
[ ] Baja funciona
[ ] Validaciones muestran error
[ ] Redirecciones mantienen contexto
[ ] SQL devuelve lo esperado
